# Code of Conduct

Headphones adopts the [CNCF Code of Conduct, version 1.3](https://github.com/cncf/foundation/blob/main/code-of-conduct.md) by reference, without changes. Headphones is not a CNCF project. It uses the CNCF text because it is clear and widely understood.

## Reporting

**Conduct contact: not yet set.** The maintainer MUST publish a dedicated conduct contact address here before the project accepts outside contributions.

Until then, report conduct concerns through a private GitHub security advisory:

1. Open the repository's Security tab.
2. Choose "Report a vulnerability".
3. Title it "Conduct report".

Only maintainers can see these advisories. Reports are handled confidentially.

## Reports about the maintainer

Headphones has one maintainer. Before the project accepts outside contributions, the maintainer will name an outside person to handle reports about the maintainer. That person's contact will be listed here.

The CNCF Code of Conduct Committee is not available to Headphones, because it is not a CNCF project.

## Enforcement

Enforcement follows the process in the CNCF Code of Conduct. Where that process names a CNCF body, the maintainer or the outside person named above takes its place.
