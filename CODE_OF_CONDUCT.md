# Code of Conduct

Headphones adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct, without changes.

## Reporting

Report conduct concerns privately to the maintainers listed in [MAINTAINERS.md](MAINTAINERS.md) through the contact address on their GitHub profile. If the concern involves a maintainer, report to another maintainer. While there is only one maintainer, reports about that maintainer may be made to GitHub through its abuse reporting process.

Reports are handled confidentially. Enforcement follows the Contributor Covenant's enforcement guidelines.
